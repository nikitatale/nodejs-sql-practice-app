A backend practice project where I learned how to connect a Node.js server with a MySQL database using the mysql2 package.
This project helped me understand server–database communication, CRUD routes, EJS templating, forms, and SQL queries.

🚀 Features

👥 Display all users

➕ Add new user

✏️ Edit existing user

❌ Delete user

🎨 EJS views with simple styling

🛠 Basic routing + form handling

📊 MySQL connection using mysql2

🛠 Tech Stack
Backend

Node.js

Express.js

MySQL

MySQL2 Package

Method-Override

Frontend

EJS Templates

Minimal CSS styling

Extras

Faker Package (for generating test users)

🎯 What I Learned

✔ Connecting Node.js to MySQL

✔ Writing SQL queries inside routes

✔ Rendering dynamic data using EJS

✔ Handling forms (POST, PATCH, DELETE)

✔ Using method-override for RESTful routes

✔ CRUD operations (Create, Read, Update, Delete)
